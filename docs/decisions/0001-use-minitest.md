# 0001: ホストアプリケーションでMinitestを採用する

- 状態: 採用
- 決定日: 2026-10-01

## 状況

Rails 8にはMinitestを使うテスト基盤が標準で用意されています。一方、Solidus本体や周辺の一部プロジェクトではRSpecが使われています。

Solidusを利用するホストアプリケーションのテスト方式を決める必要があります。

## 決定

ホストアプリケーションではMinitestを採用します。RSpecとMinitestを混在させず、アプリケーションのテストは `test/` 配下に置きます。

## 理由

- Rails標準の構成と実行コマンドをそのまま利用できる
- 追加のテストフレームワーク設定を減らせる
- 現在のリポジトリが既にRails標準の `test/` 構成を持っている
- Solidus本体がRSpecを使っていることは、ホストアプリケーションでRSpecを使う必須条件ではない
- 新規プロジェクトのため、既存RSpec資産を移行するコストが発生しない

## 影響

Solidus本体のRSpecテストやRSpec専用のヘルパーを、そのままホストアプリケーションのテストとして実行することは想定しません。Solidusの振る舞いを参照する場合は、Minitestの記法でアプリケーション側の期待する振る舞いをテストします。

将来RSpecへ変更する場合は、テストフレームワーク、ディレクトリ構成、CIコマンド、既存テストの移行方針をまとめた新しいDecisionを作成します。
