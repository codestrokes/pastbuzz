# 0006: 初期の販売・配送対象を日本国内に限定する

- 状態: 採用
- 決定日: 2026-10-01

## 状況

Solidusの店舗設定を決めるにあたり、初期リリースの販売地域と配送地域を定める必要があります。

## 決定

初期リリースの販売・配送対象は日本国内のみとします。海外への販売・配送は初期スコープに含めず、将来必要になった時点で別途判断します。

## 影響

- 通貨、ロケール、住所、税、配送方法、決済方法は日本国内での販売を前提に設定します。
- 税務・適格請求書等の要件は、実際の事業形態に応じて会計担当または専門家に確認します。
- 国際配送、複数通貨、海外税務への対応は初期リリースの要件に含めません。
