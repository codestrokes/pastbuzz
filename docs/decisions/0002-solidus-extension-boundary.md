# 0002: Solidusの拡張はホストアプリケーション側で行う

- 状態: 採用
- 決定日: 2026-10-01

## 状況

Solidusは商品、在庫、注文、決済などのEC基盤を提供します。自社要件を追加する際に、Solidus本体を変更するか、ホストアプリケーション側で拡張するかを決める必要があります。

## 決定

Solidus本体のGemは直接変更せず、ホストアプリケーション側のモデル、コントローラー、デコレーター、設定、サービスオブジェクトなどで拡張します。

Solidus標準の設定や拡張ポイントで対応できる場合は、それを優先します。

## 理由

- Gemのアップデートを適用しやすくする
- 自社固有の仕様とSolidus標準の責務を分離する
- 自社拡張だけを対象にしたテストを書きやすくする
- Solidus本体の変更を保守し続ける負担を避ける

## テストへの影響

Solidus標準の内部動作を重複して検証するのではなく、自社拡張がSolidusと正しく接続されることを検証します。標準設定を変更した場合は、変更後に期待するアプリケーションの振る舞いをテストします。
