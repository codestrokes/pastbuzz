# 0003: 外部サービスを通常のテストから分離する

- 状態: 採用
- 決定日: 2026-10-01

## 状況

認証、決済、メール、配送などの外部サービスは、ネットワーク障害、レート制限、サービス側の状態によってテスト結果が変わります。

## 決定

通常のテストスイートでは、外部サービスへの実通信を行いません。テスト用のスタブ、フェイク、またはRailsのテストアダプターを使用します。

実サービスとの疎通を確認するテストが必要な場合は、通常のテストとは別の明示的なジョブまたは環境で実行します。

## 理由

- テストを再現可能にする
- 外部サービスの障害でCI全体が失敗することを防ぐ
- 認証情報や決済情報を通常のテスト環境へ持ち込まない
- 失敗原因をアプリケーション側の不具合に絞りやすくする

## 未決定事項

具体的な認証プロバイダー、決済サービス、配送サービス、およびそれぞれのテストダブルの実装方法は、各サービスを採用する時点で決定します。
